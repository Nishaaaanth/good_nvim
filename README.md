# good_nvim

This the most complete IDE experience to have in neovim without any bloatwares and slowness!

## Plugins
* LSP
* Comment
* Git
* Harpoon
* Lualine
* Mason
* Neotree
* Noice
* Notify
* Personal Plugins
* Telescope
* Treesitter
* Which

##  NOTE: To add extra plugins, just create a new .lua file inside the plugins folder and then return the repo name
